# MORA 云间

MORA 是一款 Windows 终端音乐播放器，支持网易云音乐搜索与播放、扫码登录、个人歌单、歌词和音乐聊天。界面由键盘操作，也支持鼠标点击。运行时不需要安装 Python、Node.js 或浏览器。

![MORA 首页](docs/home-preview.png)

> 当前为 Windows x64 预览版。MORA 是独立开源项目，与网易云音乐没有隶属关系。能否播放某首歌曲取决于你的账号权限和服务端返回结果。

## 下载与启动

1. 打开 [Windows 预览版下载页](https://github.com/amu263/mora/releases/tag/v0.7.2-preview)，下载名称带 **`win-x64`** 的 ZIP。
2. 解压整个 ZIP。解压后的目录顶层应能看到 **`mora.exe`**、`mora.cmd` 和 `install.cmd`。
3. 在该目录双击 `mora.cmd`；从终端启动时，先进入解压目录，再运行 `.\mora.cmd`（CMD 与 PowerShell 均可）。

希望在任意目录输入 `mora` 时，先在解压目录运行 `install.cmd`，再**打开一个新的** CMD 或 PowerShell 窗口输入 `mora`。安装到当前用户目录，不需要管理员权限。直接运行 `mora.exe` 也可以。

**请下载 Releases 中名称带 `win-x64` 的 ZIP。** GitHub 的 **Code → Download ZIP** 和 `Source code (zip)` 是源码，不含 EXE；它们用于自行构建，不能直接运行 `mora.cmd`。

建议终端窗口至少 116×36，最低 78×24。首次启动会询问称呼，并用三页简短引导介绍听歌、登录和可选的聊天功能；按 Enter 继续，Esc 可跳过。

## 开始听歌

在底部输入命令并按 Enter。输入 `/` 可查看命令提示，Tab 可补全。

| 想做什么 | 输入 |
| --- | --- |
| 搜索歌曲 | `/search 歌名 歌手` |
| 播放搜索结果 | `/play 1`，或选中结果按 Enter |
| 暂停、下一首、上一首 | `/pause`、`/next`、`/prev` |
| 调整音量 | `/volume 65` |
| 查看当前歌词 | `/lyrics` |
| 登录网易云音乐 | `/login qr`，用 App 扫码确认 |
| 查看个人歌单 | `/library` |
| 红心或加入自己的歌单 | `/like`、`/add` |
| 选择音频设备 | `/audio-device` |
| 播放模式 | `/mode sequential`、`repeat_all`、`repeat_one`、`shuffle` |
| 歌曲详情与歌词 | `/detail`（封面、曲名歌手专辑、歌词与当前行） |
| 今天/本月/今年听了什么 | `/stats`、`/stats month`、`/stats year` |
| 让 Agent 锐评你的听歌记录 | `/review` |
| 查看端点可用的模型与能力 | `/models` |
| 查看设置或重看引导 | `/settings`、`/guide` |
| 查看全部命令 | `/help` |

可以先搜索再决定是否登录。个人歌单、红心及部分曲目的完整播放需要账号权限；扫码登录是推荐方式。请求高音质时，播放器会显示实际取得的音质，不保证每首歌都有无损或 Hi-Res。

首页会显示正在播放的歌曲（含封面、进度与音质），并可进入浏览页与歌曲详情页；浏览页的分栏与队列页同样显示当前曲目，队列页还显示播放模式与当前行。

## 播放队列

`/mode` 在四种模式间切换：顺序、列表循环、单曲循环、随机。随机模式在列表放完后会重新洗牌继续播放，切换模式不会打断正在听的歌。`/repeat on|off` 仍可用（等价于列表循环/顺序）。

## 音乐聊天（可选）

输入 `/ai`，按界面提示设置模型密钥和模型 ID，然后用 `/chat 你想听什么` 开始对话。聊天可以结合当前歌曲与歌词，也可以按你的要求使用音乐操作：搜索、播放整张专辑或歌单、按歌手或风格建立多首队列、追加到队列、跳转、删除、清空、随机与循环。

用 `K` 设置或替换密钥、`M` 修改模型 ID、`D` 清除本机密钥。在 `/ai` 中可让程序**从你填写的调用地址发现可用模型**：列出模型 ID、端点报告的模态（仅展示，用户不能自选模态）、上下文窗口与最大输出。发现结果缓存到本机配置，失败会如实显示错误码。

聊天会保留跨轮的阅读记忆（存在本机 `chat-memory.json`）。当估算的上下文接近模型窗口上限时，较早的对话会被自动压缩成一条摘要而不是被丢弃；界面会显示实际压缩条数与上下文用量，压缩降级也会照实提示。

用 `/persona` 切换助手角色，用 `/effort` 调整模型思考强度。未配置密钥不影响普通搜索和播放。

**自发评价。** 在 `/settings` 或 `/react` 中可开启"换歌时自动评价一句"，并可设置评论频率（间隔秒数）与字数；默认关闭，且每首歌最多一次、只在你停留在对话视图时触发。关闭时不产生任何模型请求。

**听歌记录与锐评。** 每次播放都会在 `%LOCALAPPDATA%\MORA\listen-log.jsonl` 记录一条本地历史；`/stats` 给出日报、月报与年报（播放次数、时长、独立歌曲与歌手、Top 曲目与歌手、时段分布）。`/review` 让模型基于这些统计写一篇约 1000 字的锐评，覆盖歌品与性格画像、特殊与高频曲目、听歌风格；字数可在设置中调整。锐评失败会如实报错，不会生成假评论。

## 数据与许可

账号会话和模型密钥使用 Windows DPAPI 加密，保存在当前 Windows 用户的 `%LOCALAPPDATA%\MORA`，**不包含在下载包或源码中**。同一台电脑上运行新版时会检测已有登录，但会先询问是否继续使用；按 `D` 可清除本机登录并改用游客模式，按 Esc 可退出。模型密钥与账号会话分开保存；在 `/ai` 中按 `D` 可清除本机模型密钥。也可用 `--data-dir` 指定独立的数据目录（同时会隔离播放会话管道，便于并行测试）。

听歌历史只记录本机曲名、歌手、专辑、时间与时长，不含 cookie、账号标识或流地址。

播放器只按账号实际拥有的音乐权限播放，不提供解锁或绕过服务限制的功能。

## 从源码构建

源码包和 GitHub 自动生成的源码快照不包含预编译 EXE。需要 Windows x64、Python（仅用于下载构建工具）和 PowerShell：

```powershell
python scripts/bootstrap.py
./build.ps1
./build.ps1 -Test
```

构建完成后运行 `./mora.cmd`。发行版 ZIP 不包含开发用原始肖像。
